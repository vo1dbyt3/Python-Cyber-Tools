# Python Port Scanner

## Overview

A simple Python-based port scanner built to explore network programming and understand how open ports can be identified on a target host.

## Features

* Scans a specified host for open TCP ports.
* Uses Python sockets to test port connectivity.
* Helps demonstrate how network services can be discovered.
* Provides hands-on practice with TCP connections and port numbers.

## Technologies

* Python 3
* `socket` module

## Usage

Run the script:

```bash
python3 port_scanner.py
```

Follow the prompts or configuration defined in the script to specify the target host and ports.

## What I Learned

* TCP connections and port numbers.
* Python socket programming.
* Basic network reconnaissance concepts.
* Handling connection errors and timeouts.

## Disclaimer

Use this tool only on systems you own or have explicit permission to test. Unauthorized scanning may violate applicable laws or policies.
